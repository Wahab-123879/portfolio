# Personal Portfolio Website

A sleek, responsive, and modern developer portfolio website built with Semantic HTML5, Tailwind CSS, Vanilla JavaScript, and Lucide Icons.

## Quickstart

Open `index.html` directly in a browser, or use VS Code Live Server.

## Features

- Dark / Light theme toggle
- Animated typing hero
- Responsive layout and mobile navigation
- Project category filters
- Project detail modal
- Contact form interaction feedback

## Deployment

GitHub Pages can be enabled in the repository settings by selecting the main branch as the Pages source.

Once enabled, the site will be available at:

https://wahab-123879.github.io/portfolio/
